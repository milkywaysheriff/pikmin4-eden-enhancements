# Source download

The separate `Sources.zip` contains the exact allowlisted `pchtxt` inputs,
new ARM64 helper sources/linker scripts, publication documents, pinned input
catalog and a portable Python packaging script. No personal profiles,
diagnostic captures, Nintendo executables, keys or saves are included.

From the extracted Sources directory, rebuild both public ZIPs with:

```sh
python3 tools/build_release.py
```

This needs only Python 3.9+ standard library. It writes into `dist/`, never
reads an Eden profile and never installs anything. ZIP member ordering and
timestamps are fixed. Same Python/zlib implementation reproduces identical
archives; compression versions can change ZIP hashes without changing payloads.

The `pchtxt` files are the authoritative patch source for FPS v4, camera v3,
DR Lock v5 and hook sites. The newer helper assembly is included for review
and reassembly with LLVM (`clang --target=aarch64-none-elf`, `ld.lld`,
`llvm-objcopy`). With LLVM installed, compare all supplied helper sections
against the distributed patches without a game dump:

```sh
python3 tools/verify_sources.py
```

This source download reproduces the release packaging from
checked-in patch templates; it does not claim to reconstruct every older
template from standalone assembly or rerun the private full-dump analyses.

A41 includes helper bytes from A38/A40 plus its own additions. A45's
3440×1440 variant is generated by replacing only its 24-byte UTF-16 viewport
string at `0x062F0D40`; all A45 code and other writes remain identical.
No legacy 32:9, old output-only patches or withdrawn experiments are shipped.

Gameplay evidence and its limits are documented in `VERIFICATION.md` in
the playable download and `docs/VERIFICATION.md` in this source tree.
Credits and provenance are in the adjacent `CREDITS.md`.
