# Pikmin 4 1.1.1 — Eden Enhancements 1.0 beta 1

First public prerelease by **gallongg**.

**Download `Pikmin4_1.1.1_Eden_Enhancements_1.0-beta1.zip` for the mods.**
The `_Sources.zip` attachment contains the patch templates, ARM64 helper
sources, packaging tools and documentation. `SHA256SUMS.txt` identifies
the release attachments. GitHub's automatic source archives are repository
snapshots; they are not the prepared mod download.

Included: FPS60/120/180, cumulative Pikmin movement/timing A41, five camera
rotation speeds, per-view ultrawide5120×2160 and3440×1440 A45, CA OFF and
Dynamic Resolution Lock. Choose one variant per FPS/camera/ultrawide group.
Each FPS option requires its main+SDK files and the separate A41 timing mod.

The local tester confirms **corrected Dandori split-screen 3D proportions
at5120×2160 with A45**. The latest recorded run uses FPS60. The exact
3440×1440 A45 variant and FPS180 have not been play-tested locally. The
extended A41 paths and CA OFF lack separate controlled confirmation.
Following/boarding improvements were reported for earlier cumulative
components; achieved FPS was not captured during those successful tests.

For ultrawide: Eden **1×**, GPU accuracy **High**, Stretch to Window and
a matching21:9 image area. Keep emulation speed100%. No guaranteed120FPS,
measured native3D resolution or complete timing coverage is claimed.

Close Eden before installing/removing patches. Back up old equivalent
mods and copy only your chosen `P4 - ...` folders into the game's mod
location. Full installation and rollback instructions are in the download.

Release preparation checks cover288 permitted selections for byte overlap,
fixed input hashes, syntax/Build IDs and archive extraction.516 bytes of
new helper assembly were independently rebuilt and matched locally.
These are offline checks, not additional gameplay tests.

Pikmin4 **update1.1.1 only**. No game files, keys, firmware, saves or
personal emulator profiles are included. Stop Talking is not bundled.
Credits and development/test limitations are documented in the repository.
